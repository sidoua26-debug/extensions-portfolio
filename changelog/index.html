Word to LaTeX (Offline)

v1.0.6 (Current)

  • Upgraded Pandoc WebAssembly engine with streaming decompression.
  • Added experimental offline math OCR with local Tesseract.js.
  • Enhanced table conversion with booktabs and longtable environments.
  • Fixed \tightlist and \pandocbounded{} wrapper normalization.

v1.0.0

  • Initial public release on Microsoft Edge Add-ons.
  • Offline client-side DOCX to LaTeX conversion.

Table Extractor

v1.2.0 (Current)

  • Enhanced virtualized grid detection (AG Grid, Handsontable).
  • Added UTF-8 BOM encoding for seamless Microsoft Excel import.
  • Granular column filtering and hidden column restoration.
  • Export presets for CSV, XLSX, and JSON arrays.

v1.0.0

  • Initial dual release on Microsoft Edge Add-ons and Chrome Web Store.

BulkGrab

v1.1.2 (Current)

  • Non-intrusive Shadow DOM floating download panel.
  • Instant category filtering for PDFs, archives, images, and audio.
  • Client-side ZIP bundling via JSZip on-device.
  • Zero cloud telemetry; direct-to-disk stream downloads.

v1.0.0

  • Initial release on Microsoft Edge Add-ons and Chrome Web Store.

SEO Inspector

v1.3.1 (Current)

  • 9 comprehensive technical SEO diagnostic tabs.
  • Heading hierarchy tree visualizer (H1-H6).
  • Schema.org JSON-LD parser and syntax validator.
  • Page timing metrics via Navigation Timing API (TTFB, DOMContentLoaded, load).

v1.0.0

  • Initial release on Microsoft Edge Add-ons.

Bilexi

v1.0.0 (Current)

  • Initial public release on Microsoft Edge Add-ons.
  • 100% offline bilingual English/French autocorrect engine.
  • Instant French accent restoration (ecole → école).
  • Interactive Alt+2 / Alt+3 hotkey replacement strip.
  • Zero cloud telemetry, zero remote dictionary lookups.

Tab Vault

v1.0.0 (Current)

  • Initial public release on Microsoft Edge Add-ons.
  • One-click window collapse and restore reclaiming browser memory.
  • Defense-in-depth disaster recovery with rolling snapshots and JSON backup rotation.
  • Omnibox tv <query> integration and real-time instant search.
  • 100% local storage with zero cloud telemetry.
