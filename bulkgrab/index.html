BulkGrab

Deep-scan webpages for downloadable files, filter by extension, and bundle them into a local ZIP archive.

Get on Chrome Get on Edge GitHub (@sidoua26-debug)

Why Use a Privacy-First Batch Downloader?

Most bulk downloaders require excessive browser permissions, inject adware into pages, or route your file links through third-party tracking redirectors.

BulkGrab streams downloads directly from the source host website into your browser storage and packages ZIP archives locally on-device using JSZip. No download URLs, filenames, or content metadata are ever logged.

Key Capabilities

Smart Extension Filtering

Filter links by images (PNG, JPG, WEBP, SVG), documents (PDF, DOCX, XLSX), media (MP4, MP3), or custom regex.

On-Device ZIP Packaging

Bundle hundreds of discovered links into a single compressed ZIP archive locally in memory.

Batch Renaming & Sequence

Organize downloaded files with custom naming rules, timestamps, and sequential numbering.

No Link Tracking

Direct browser streaming ensures your download history remains strictly confidential.

How to Use

1

Open Target Page

Visit any webpage with multiple documents, images, or media assets.

2

Activate BulkGrab

Launch the floating Shadow DOM panel to scan and filter discovered files by extension.

3

Download or Archive

Save files individually or bundle selected items into a client-generated ZIP file.

Good to Know

Direct Browser Downloads

Your browser connects directly to asset source servers; downloads connect directly to the asset host.

Shadow DOM UI

The floating download overlay is isolated from the host page stylesheet to prevent visual conflicts.

Local ZIP Bundling

ZIP archives are constructed in memory on-device using JSZip before being saved to your downloads folder.

Frequently Asked Questions

Can BulkGrab download all images from a webpage at once?

Yes, BulkGrab identifies all inline image tags, picture elements, and background CSS URLs for batch downloading.

Does BulkGrab send my download links to external servers?

No. Your browser requests downloads directly from the source site; they do not pass through our servers.

Is BulkGrab available on Chrome and Edge?

Yes, BulkGrab is verified and published on both Microsoft Edge Add-ons and the Chrome Web Store.
