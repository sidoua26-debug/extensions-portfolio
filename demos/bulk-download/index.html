How to Test with BulkGrab & Browser Considerations

1. Install & Open Floating Panel

Install BulkGrab from Microsoft Edge Add-ons or Chrome Web Store. Click the extension toolbar icon to open the floating Shadow DOM panel on this page.

2. Apply File Type Filters

Use the smart filter pills to select documents (.pdf, .csv) or images (.png, .jpg).

3. Bundle into Local ZIP (Pro)

Choose ZIP packaging (requires BulkGrab Pro) to bundle selected items into a single compressed file assembled locally in browser memory via JSZip before saving.

Understanding Browser Download Limitations

  • Same-Origin vs Cross-Origin Restrictions: The HTML5 download attribute only suggests filenames for same-origin assets. Cross-origin files stream directly from third-party hosts and default to the remote server's content-disposition header. (All sample files on this playground are same-origin assets hosted locally on extensionguy.me; cross-origin behavior is explained for technical context but is not simulated by these same-origin fixtures.)
  • Browser Concurrency Throttling: Web browsers limit simultaneous parallel downloads (typically 6 per origin). Extensions queue requests to prevent connection drops.
  • Free Tier & Pro Scope: BulkGrab Free allows up to seven individual file downloads per browser session. BulkGrab Pro removes that session limit and adds ZIP bundling on your device. The optional Pro upgrade ($9.99 USD via NOWPayments) unlocks unrestricted batch downloads and archiving.
