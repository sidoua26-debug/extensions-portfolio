Word to LaTeX (Offline)

A dedicated browser extension that converts Microsoft Word manuscripts, clipboard tables, and typed math images into compilation-ready LaTeX snippets — completely inside your browser.

Pandoc WebAssembly
Verified 460px Chromium Popup Interface 1280×800 Native Capture
Microsoft Edge Verified Zero Permissions Requested Version 1.0.5

Preserves Complex Word Structure

Extracts headings, bold/italics, nested lists, alignment (center/flushright), page geometry, and tables directly into clean booktabs and longtable syntax.

Instant Clipboard Synchronization

Generates clean body fragments ready to paste directly into Overleaf or TeXstudio. Automatically unwraps \pandocbounded{} and removes \tightlist artifacts.

Offline Image to LaTeX (OCR)

Built-in Tesseract.js engine (English, French, Math) recognizes typed single-line equations, standard Greek characters, and definite integrals locally.

Transparent Scope & Limitations: Image OCR is experimental and tested against an 80-sample golden evaluation corpus (97.5% compile rate). Radicals (√) are often read as V, matrix grids are unreliable, and handwriting is unsupported. Always review OCR output before publication.

Installation Guide

Simple Installation on Microsoft Edge

Install directly from the Microsoft Edge Add-ons store in one click, or test unpacked builds via Developer Mode.

1

Open Store Page

Click "Get on Edge" on any extension above to open its verified Microsoft Edge Add-ons listing.

2

Click "Get"

Click the blue Get button. Edge will prompt to verify the minimal permissions requested.

3

Pin to Toolbar

Click the puzzle icon in Edge's toolbar and select the pin icon next to the extension for instant access.

4

Developer Unpacked

For offline testing: download the release ZIP from GitHub, open edge://extensions, toggle Developer mode, and click Load unpacked.
