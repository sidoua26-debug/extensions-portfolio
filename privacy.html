This Privacy Policy provides clear, transparent disclosures regarding how data is handled when you visit this website (the "Site") and when you install and use our browser extensions. This document explains the exact scope of data processing, device storage, browser permissions, and third-party infrastructure.

1. Scope & Distinction

It is important to distinguish between:

  • The ExtensionGuy Portfolio Website (extensionguy.me): A static, publicly accessible website presenting extension documentation, interactive previews, and an in-browser WebAssembly converter demo.
  • The Published Browser Extensions: Independent client software packages installed into your browser from official add-on marketplaces (Microsoft Edge Add-ons and Google Chrome Web Store). Each extension runs under its own distinct permission model within your browser sandbox.

2. Website Visitors (extensionguy.me)

The Site is built as a static client-side web application. We have engineered the site to minimize data exposure:

  • No First-Party Analytics or Advertising Trackers: We do not embed first-party analytics scripts, Google Analytics, tracking pixels, marketing cookies, or fingerprinting scripts.
  • Local Storage (Theme Preference): When you toggle between Light and Dark mode on pages with theme controls, the site saves your choice (theme) in your browser's local storage (localStorage). This value remains on your device and is not transmitted to server endpoints.
  • In-Browser Converter Demo: The live Word-to-LaTeX demonstration executes entirely on your hardware. It downloads the Pandoc WebAssembly binary (assets/wasm/pandoc.wasm.gz) from our static host, starts an in-browser Web Worker, and converts documents in memory. No document content, extracted text, or generated LaTeX snippets are transmitted to remote servers.
  • Hosting and Infrastructure Server Logs: The Site is hosted on and served through Cloudflare Pages. When your browser requests static files, Cloudflare automatically processes standard HTTP request metadata necessary for content delivery, DDoS mitigation, security, and edge caching (such as your IP address, browser User-Agent, request URL, and timestamp). Cloudflare handles this operational data in accordance with its own Privacy Policy. We do not combine these infrastructure logs with personal profiles.
  • Self-Hosted Fonts & Assets: All stylesheets, typography (Geist and JetBrains Mono WOFF2 font files), icons, images, and WebAssembly binaries are served directly from the same static origin or edge cache. There are no runtime requests to Google Fonts, remote CDNs, or external script hosts.

3. Browser Extensions: Data Processing & Storage

Every browser extension published by ExtensionGuy is designed to operate locally on your computer without application-level telemetry or background user tracking. The specific data practices for each extension are detailed below:

Word to LaTeX (Offline)

  • Data Processed: Word documents (.docx), XML markup, mathematical equations (OMML/MathML), document tables, and plain text pasted or dropped into the interface.
  • Processing Location: Processed locally in browser memory via WebAssembly (Pandoc WASM) and a dedicated Web Worker.
  • Network Transmission: None. The extension declares no host permissions (host_permissions: []) and no background network permissions, designed to operate without remote server communication.
  • Storage & Retention: Temporary in-memory processing. Document buffers and parsed results are cleared when the conversion tab or modal is closed. No files are uploaded or stored remotely.

Table Extractor

  • Data Processed: HTML table elements and virtualized data grid structures (such as AG Grid or handsontable) rendered in the active browser tab you select.
  • Processing Location: Client-side execution in the active tab context. Table DOM elements are parsed in memory, and export files (CSV, XLSX with UTF-8 BOM, and JSON) are compiled directly on-device.
  • Network Transmission: Extracted table data, cell values, and compiled spreadsheets are never transmitted to external servers. Ordinary table extraction runs locally on your machine with no accounts or cloud API keys required. Optional Pro licensing functionality is described in Section 4 below.
  • Storage & Permissions: Uses activeTab and scripting on demand when invoked. Uses storage to save display preferences and license tier status in chrome.storage.local. No table contents are written to persistent remote storage.

BulkGrab

  • Data Processed: Publicly accessible media URLs, image links, and downloadable document links discovered in the DOM of the active tab you choose to inspect.
  • Processing Location: On-device link filtering and client-side ZIP packaging using bundled client libraries (JSZip).
  • Network Transmission: Your browser requests downloads directly from the source site; they do not pass through our servers. When bundling files from external domains into a local ZIP archive, the extension requests the optional <all_urls> permission to fetch the binary file content directly into local memory. Optional Pro licensing functionality is described in Section 4 below.
  • Storage & Permissions: Uses downloads to save files to your local download directory, activeTab and scripting to detect page links on demand, storage for user options, and optional <all_urls> for cross-site ZIP bundling.

SEO Inspector

  • Data Processed: On-page technical metadata from the active tab: title tags, meta descriptions, canonical URLs, heading structure (H1–H6), Open Graph tags, JSON-LD structured data scripts, and browser Performance / Navigation Timing benchmarks (TTFB, DOMContentLoaded, load time).
  • Processing Location: Client-side inspection within browser memory.
  • Network Transmission: None. Evaluates active tab DOM and Performance Navigation Timing APIs locally; declares no host permissions or remote telemetry endpoints.
  • Storage & Permissions: Uses activeTab and scripting on demand. User preferences (such as display options) are saved locally via chrome.storage.local, remaining on your device.

Bilexi

  • Data Processed: Text typed or edited in browser input fields, textareas, or content-editable elements where autocorrect is enabled, specifically for French accent restoration and bilingual English/French spelling checks.
  • Processing Location: Local memory processing against bundled binary dictionary files. Keystrokes are evaluated locally without contacting remote language APIs or third-party spellcheck servers.
  • Network Transmission: Evaluates text locally against bundled offline dictionaries without contacting remote language APIs. Declares optional host permissions (optional_host_permissions: ["*://*/*"]) strictly for on-page text element inspection across web pages.
  • Storage & Retention: User-defined custom dictionary words, ignored words, and user preferences are stored strictly on your device via chrome.storage.local. You can view or clear this custom vocabulary at any time through the extension settings.

Tab Vault

  • Data Processed: URLs, page titles, and window groupings of open browser tabs that you explicitly choose to stash, suspend, or organize.
  • Processing Location: Local execution within the browser runtime. Tab grouping, memory suspension, and omnibox search queries (tv <query>) operate on-device.
  • Network Transmission: None. Operates without remote backend servers or cloud sync APIs; tab data remains in local browser storage.
  • Storage & Retention: Stashed tab collections, Quick Lists, and rolling auto-snapshots are stored on-device in your browser's local IndexedDB and chrome.storage.local. Deleted tabs are moved to a local 30-day soft trash archive managed on your device, which you can purge immediately. You can export or import your entire vault as a local JSON file at any time.
  • Permissions: Declares tabs (to read and restore open tab titles and URLs), storage and unlimitedStorage (for IndexedDB and local preference persistence), alarms (for scheduled local rolling snapshots), downloads (for manual JSON backup exports), offscreen (to create local Blob URLs for large backup exports exceeding 2MB without freezing the service worker), and contextMenus (for right-click tab-stashing shortcuts).

4. Optional Pro Licensing (Table Extractor & BulkGrab)

Optional Pro licensing for Table Extractor and BulkGrab attempts to verify payment IDs via an intermediary proxy when browser permissions allow; under no circumstances are table contents, extracted spreadsheets, downloaded files, or media URLs transmitted to the licensing service, as disclosed in our Privacy Policy.

  • Scope: Pro licensing is strictly optional and applies only to Table Extractor and BulkGrab. All core table extraction, spreadsheet compiling, link discovery, and downloading features operate without licensing.
  • Stage A — Extension to Cloudflare Worker Proxy: The extensions attempt to contact an intermediary Cloudflare Worker (bulkgrab-licensing.sidoua26.workers.dev). For invoice creation, Table Extractor transmits {"product": "table-extractor"}. For payment verification, Table Extractor submits query parameters containing the user-provided payment ID and product identifier (payment_id=<id>&product=table-extractor), while BulkGrab transmits payment_id=<id>. Promotional gift codes with prefix TE-GIFT- are validated strictly in local JavaScript and generate no network requests. When an outbound request reaches the Worker proxy, Cloudflare processes standard HTTP connection metadata (client IP address, request timestamp, and headers).
  • Stage B — Cloudflare Worker to NOWPayments: When an invoice creation request reaches the Worker proxy, the Worker generates the order metadata and submits invoice parameters to NOWPayments (NOWPayments Privacy Policy). For verification requests, the Worker queries NOWPayments using the payment ID. Neither stage ever transmits table contents, extracted files, page URLs, or browsing history.

5. Hosting & Third-Party Infrastructure

When you interact with external services, their respective privacy policies govern your data:

  • Cloudflare Pages (Website Hosting): The Site is hosted on Cloudflare Pages. Content delivery, DDoS mitigation, and edge caching are handled in accordance with the Cloudflare Privacy Policy.
  • Browser Add-on Marketplaces: Installing extensions through the Microsoft Edge Add-ons catalog or the Chrome Web Store is governed by Microsoft's and Google's store terms and privacy statements. Marketplaces may collect installation counts and crash telemetry according to your browser settings.
  • Cryptocurrency Licensing Gateway (NOWPayments): For users who optionally choose to initiate license purchases in Table Extractor or BulkGrab, payment processing is handled through NOWPayments (NOWPayments Privacy Policy).
  • GitHub: Links to source code repositories or developer profiles point to GitHub, which collects visitor and account information under GitHub's Privacy Statement.
  • External Target Websites: When you use extensions like Table Extractor or BulkGrab on target websites, those websites maintain their own independent privacy policies and terms.

6. User Control & Data Deletion

You retain full control over your software and local data at all times:

  • Clearing Extension Data: You can clear all locally stored data, dictionaries, tab vaults, and configuration settings by clearing your browser's extension data or storage in browser settings.
  • Uninstalling Extensions: You can remove any extension at any time via your browser's extension management page (edge://extensions or chrome://extensions). Uninstalling an extension prompts the browser to remove the extension's local storage database and stops all background script execution.
  • Site Preferences: You can clear the website theme preference at any time by clearing your browser cookies and site data for extensionguy.me.
