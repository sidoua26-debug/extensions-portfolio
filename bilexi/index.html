Bilexi

Offline bilingual English/French autocorrect with instant accent restoration and elision repair.

Get on Edge GitHub (@sidoua26-debug)

Why Choose an Offline Bilingual Autocorrect?

Many cloud-based grammar checkers and AI writing assistants transmit drafts or typing sessions to remote servers for processing and cloud analysis.

Bilexi processes text offline on your device using compact binary trie dictionaries. Keystrokes do not leave your machine, ensuring strong privacy for confidential communications.

Key Capabilities

Accent Restoration

Automatically restores missing French accents in real time (e.g., ecole → école, deja → déjà).

Elision Repair

Corrects French apostrophe elisions (e.g., j ai → j'ai, l arbre → l'arbre) effortlessly.

Interactive Suggestion Strip

Quickly cycle through autocorrect recommendations with keyboard shortcuts (Alt+2 / Alt+3).

Offline Architecture

Processes text locally in browser memory without contacting remote language servers.

How to Use

1

Type Naturally

Write English or French text in any standard web input, textarea, or editor.

2

View Suggestions

Notice real-time accent restorations (ecole → école) and elision fixes as you type.

3

Quick Hotkeys

Use keyboard shortcuts Alt+2 or Alt+3 to cycle and accept suggestion candidates instantly.

Good to Know

Bundled Dictionaries

Word lists and grammatical rules are packaged inside the extension; no keystrokes are sent across the network.

Bilingual Recognition

Automatically distinguishes English and French context without requiring manual language toggling.

Privacy First

Only evaluates text locally in active editable elements without monitoring background browsing.

Frequently Asked Questions

Does Bilexi transmit my keystrokes to remote servers?

Bilexi evaluates text locally against bundled offline dictionaries without contacting remote language APIs.

Can I use Bilexi for both French and English at the same time?

Yes! Bilexi seamlessly handles mixed bilingual writing without requiring you to switch language modes.

Where can I download Bilexi?

Bilexi is officially published on Microsoft Edge Add-ons and is available to install with one click.
