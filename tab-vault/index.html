Tab Vault

Fast, privacy-first tab manager reclaiming browser memory with defense-in-depth disaster recovery and instant search.

Get on Edge GitHub (@sidoua26-debug)

Why Choose a Crash-Resilient Tab Manager?

Having dozens of tabs open slows your browser to a crawl, draining battery and consuming gigabytes of system memory. Yet traditional tab managers frequently lose data to unexpected browser crashes, profile resets, or accidental group deletions.

Tab Vault converts open windows into clean, timestamped sessions in a single click—reclaiming browser memory while protecting your tabs with rolling snapshots, automated JSON backups, and a 30-day soft trash bin.

Key Capabilities

One-Click Stash & Restore

Collapse entire windows or individual tabs into structured groups with instant memory reclamation.

Defense-in-Depth Disaster Recovery

Rolling 5-state safety snapshots and automated 3-file rotating backups to your Downloads folder protect saved tabs against profile corruption.

Instant Search & Omnibox

Type tv <query> in the browser address bar for responsive, on-device search across thousands of locally saved tabs.

100% Local & Private

No remote telemetry or cloud databases. All tab URLs, titles, and metadata stay strictly on your device.

Frequently Asked Questions

How does Tab Vault reduce browser memory usage?

Open browser tabs consume significant RAM and CPU cycles for DOM trees, running scripts, and cached media. Tab Vault converts open tabs into lightweight, persistent list items, freeing system memory while keeping your links instantly searchable and restorable.

Does Tab Vault transmit my tabs or browsing history to any server?

Tab Vault operates 100% locally on your machine with no remote network calls, no analytics trackers, and no external servers. Tab Vault does not request the browser history permission and does not access or track your general browsing history—it accesses open tabs only when you explicitly stash or organize them. All saved tab collections remain strictly in local extension storage (chrome.storage.local).

How does Tab Vault protect against tab loss and browser profile crashes?

Tab Vault features defense-in-depth disaster recovery. In addition to a 5-state in-memory snapshot buffer in chrome.storage.local, it automatically writes rotating backup files to your browser's default download folder across three fixed filenames: tab-vault-backup-1.json, tab-vault-backup-2.json, and tab-vault-backup-3.json. These automated backups run in the background once every 24 hours and 5 minutes after session collapses (in addition to manual exports initiated from the dashboard). The backups are unencrypted JSON files containing saved tab URLs, query parameters, page titles, and timestamps (incognito tabs are excluded).
